Wilayah Indonesia API

API statis (JSON) untuk data Provinsi, Kota/Kabupaten, Kecamatan, dan Desa/Kelurahan di Indonesia berdasarkan Keputusan Mendagri No 100.1.1-6117 Tahun 2022.

Base URL: https://wilayah.darisdzakwanhoesien.site
Sumber data & kode generator: github.com/darisdzakwanhoesien2/clone_wilayah
Contoh dropdown bertingkat: /demo.html

GET/api/provinces.json

Daftar seluruh provinsi.

curl https://wilayah.darisdzakwanhoesien.site/api/provinces.json
[
  { "id": "11", "name": "ACEH" },
  { "id": "12", "name": "SUMATERA UTARA" },
  ...
]

GET/api/regencies/{province_id}.json

Daftar kota/kabupaten dalam satu provinsi.

curl https://wilayah.darisdzakwanhoesien.site/api/regencies/11.json
[
  { "id": "1101", "name": "KAB. ACEH SELATAN" },
  { "id": "1102", "name": "KAB. ACEH TENGGARA" },
  ...
]

GET/api/districts/{regency_id}.json

Daftar kecamatan dalam satu kota/kabupaten.

curl https://wilayah.darisdzakwanhoesien.site/api/districts/1101.json

GET/api/villages/{district_id}.json

Daftar desa/kelurahan dalam satu kecamatan.

curl https://wilayah.darisdzakwanhoesien.site/api/villages/110101.json

Skema ID

LevelPanjang IDContoh
Provinsi2 digit11
Kota/Kabupaten4 digit (diawali kode provinsi)1101
Kecamatan6 digit (diawali kode kota/kabupaten)110101
Desa/Kelurahan10 digit (diawali kode kecamatan)1101012001

Contoh: dropdown bertingkat (JavaScript)

const res = await fetch(`/api/regencies/${provinceId}.json`);
const regencies = await res.json();
// regencies: [{ id, name }, ...] → isi ke <select>

Catatan

File-file ini statis (tidak ada rate limit, tidak butuh API key) dan di-generate dari csv/*.csv lewat scripts/generate_api.py. Untuk data mentah lengkap (termasuk hierarki penuh per baris) lihat folder csv/ atau dump SQL di root repo.

Data BELUM/TIDAK termasuk perubahan pembentukan provinsi baru (Papua Barat Daya). Lihat README repo untuk detail.
